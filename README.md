# صدفة — دردشة فيديو عشوائية

تطبيق ويب للدردشة بالفيديو مع أشخاص عشوائيين (على طريقة Omegle / OmeTV).
الفيديو والصوت يمرّان مباشرة بين المتصفحين عبر **WebRTC**، والخادم يقوم فقط بالمطابقة وتمرير إشارات الاتصال.

## التشغيل

```bash
npm install
npm start
```

ثم افتح `http://localhost:3000` في نافذتين (أو جهازين) واضغط «ابدأ».

## المميزات

- مطابقة عشوائية فورية مع زر «التالي» (أو مفتاح `Esc`)
- دردشة نصية مع مؤشر «يكتب…»
- كتم الميكروفون / إيقاف الكاميرا
- عدّاد المتصلين الآن
- بوابة دخول (+18 والموافقة على القواعد)
- زر إبلاغ: 3 بلاغات من أشخاص مختلفين خلال ساعة = حظر لمدة ساعة
- لا يعاد ربطك فوراً بنفس الشخص الذي تخطيته
- إن لم تتوفر كاميرا تُرسل صورة بديلة ويبقى بالإمكان الدردشة كتابياً
- واجهة عربية (RTL) متجاوبة مع الهاتف

## الملفات

| الملف | الوظيفة |
|---|---|
| `server.js` | Express + Socket.IO: الطابور، المطابقة، تمرير الإشارات، الدردشة، البلاغات |
| `public/index.html` | الواجهة |
| `public/styles.css` | التصميم |
| `public/app.js` | الكاميرا، WebRTC، أحداث الواجهة |

## النشر على الإنترنت

- المتصفحات لا تسمح بالكاميرا إلا عبر **HTTPS** (أو `localhost`)، لذلك انشره على منصة توفر HTTPS مثل Render أو Railway أو Fly.io (أمر التشغيل: `npm start`).
- خوادم STUN المجانية تكفي لمعظم الشبكات، لكن حوالي 10–20% من المستخدمين (شبكات الجوال والشركات) يحتاجون خادم **TURN**. أضفه عبر متغيرات البيئة:

```bash
TURN_URL=turn:your-turn-server:3478 TURN_USERNAME=user TURN_CREDENTIAL=pass npm start
```

- كل البيانات (الطابور، البلاغات، الحظر) في الذاكرة وتُمسح عند إعادة تشغيل الخادم.
